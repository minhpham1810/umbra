# Umbra — Product Steering

Umbra is a TypeScript 3D game engine built for AI agents.
Every run is deterministic and replayable.
Agents drive it through typed tools only — they never touch the browser.

## Two games

| | Lantern | Boo & Co. |
|---|---|---|
| Folder | `games/lantern/` | `games/boo-and-co/` |
| Genre | 3rd-person dark platformer | Top-down bright management sim |
| What agents hunt | Unreachable goals, fall-throughs, softlocks | Unwinnable quotas, dominant strategies, crowd deadlocks |
